操作方式

· 点击屏幕上的图标进入应用，导航栏左上角返回、右上角两个按钮回桌面
· 状态栏（底部）：左侧切电量/电压，中间开控制中心，右侧切 24h / 12h / CPU
· 音乐页：点封面或频谱条切歌词，拖动进度条跳转
· 桌面：左右拖动或按 ← → 翻页
· 记事本：列表翻页 / 点条目编辑 / 新建；有未保存改动时点「列表」或导航栏返回会先弹 保存 / 不保存 / 取消
· 开机页：拖动左摇杆移动光标，角色立绘随之漂移（固件 start_unit 的视差动效）
· 快捷键：Esc 返回，Enter 控制中心
